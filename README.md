# Windows PowerShell Lab – SOC Class

## Overview

This project documents a practical Windows PowerShell lab completed during my SOC (Security Operations Center) class.

The lab focused on using Command Prompt and PowerShell for basic Windows administration, network troubleshooting, and security-related observation.

## What I Practiced

- Accessing Command Prompt and PowerShell
- Using common commands such as `dir`, `cd`, `ping`, and `ipconfig`
- Understanding PowerShell aliases and cmdlets
- Checking network connections and routing information with `netstat`
- Running PowerShell with elevated (Administrator) privileges
- Viewing active TCP connections and associated process information
- Using PowerShell to manage Windows tasks

## Commands Practiced

```text
dir
cd
ping 8.8.8.8
ipconfig
Get-Alias dir
netstat -h
netstat -r
netstat -abno
clear-recyclebin
```

## Key Learning

During my SOC class, I learned how PowerShell can be used as a practical tool for Windows administration, network troubleshooting, and security monitoring.

I also practiced comparing Command Prompt and PowerShell commands and observing active network connections and routing information.
